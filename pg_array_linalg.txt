Разработать расширение pg_array_linalg для PostgreSQL, реализующее набор функций для векторных и матричных вычислений.

Общие требования:
1) Расширение должно быть реализовано на языке С;
2) Функции должны работать с 1 и 2-мерными числовыми массивами (векторы, матрицы). В случае некорректных входных данных должно выводиться сообщение об ошибке;
3) Для 2-мерных массивов функция по умолчанию работает с первой размерностью, если аргументы не подразумевают иное;
4) Значение NULL должно обрабатываться корректно, NULL != NULL;
5) Функции должны быть IMMUTABLE;
6) Для каждой функции необходимо реализовать набор тестов, проверяющий ее работу на корректных и некорректных данных, со всеми возвращаемыми функцией вариантами ошибок;
7) Для каждой функции необходимо описать существующие ограничения, в т.ч. описать возможные диапазоны (значения) входных и выходных данных;
8) Для каждой функции необходимо провести серию замеров, собрать статистику и построить график по зависимости времени выполнения от объема входных данных

Необходимо реализовать следующие функции:
1) Скалярное произведение двух векторов (одномерных массивов одинаковой длины)
array_dot ( anyarray, anyarray ) → numeric

SELECT array_dot(ARRAY[1,2,3], ARRAY[4,5,6]); 
-- 14 + 25 + 3*6 = 32

2) Умножение матриц. Первый аргумент – матрица A размерности m×n, второй – матрица B размерности n×p. Результат – m×p.
array_matmul ( anyarray, anyarray ) → anyarray

-- A(2x2) * B(2x2)
SELECT array_matmul(ARRAY[[1,2],[3,4]], ARRAY[[5,6],[7,8]]); 
-- {{19,22},{43,50}}

3) Транспонирование матрицы (меняет местами строки и столбцы).
array_transpose ( anyarray ) → anyarray

SELECT array_transpose(ARRAY[[1,2,3],[4,5,6]]); 
-- {{1,4},{2,5},{3,6}}

4) Определитель квадратной матрицы (для типа numeric).
array_det ( anyarray ) → numeric

SELECT array_det(ARRAY[[1,2],[3,4]]); 
-- -2

5) Обратная матрица (если существует).
array_inv ( anyarray ) → anyarray

SELECT array_inv(ARRAY[[2,0],[0,2]]); 
-- {{0.5,0},{0,0.5}}

6) Решение системы линейных уравнений A * x = b, где A – квадратная матрица, b – вектор. Возвращает вектор x.
array_solve ( a anyarray, b anyarray ) → anyarray

SELECT array_solve(ARRAY[[2,1],[1,1]], ARRAY[5,3]); 
-- {2,1}
