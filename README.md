# Дизайн-документ: pg_array_linalg

## 1. Задача

Разработать расширение `pg_array_linalg` для PostgreSQL на языке C, реализующее набор функций для векторных и матричных вычислений.

**Общие требования:**
1) Расширение должно быть реализовано на языке С;
2) Функции должны работать с 1 и 2-мерными числовыми массивами (векторы, матрицы). В случае некорректных входных данных должно выводиться сообщение об ошибке;
3) Для 2-мерных массивов функция по умолчанию работает с первой размерностью, если аргументы не подразумевают иное;
4) Значение NULL должно обрабатываться корректно, NULL != NULL;
5) Функции должны быть IMMUTABLE;
6) Для каждой функции необходимо реализовать набор тестов, проверяющий ее работу на корректных и некорректных данных, со всеми возвращаемыми функцией вариантами ошибок;
7) Для каждой функции необходимо описать существующие ограничения, в т.ч. описать возможные диапазоны (значения) входных и выходных данных;
8) Для каждой функции необходимо провести серию замеров, собрать статистику и построить график по зависимости времени выполнения от объема входных данных

**Функции:**
- `array_dot` — скалярное произведение двух векторов (одномерных массивов одинаковой длины)
- `array_matmul` — умножение матриц `A(m*n)` на `B(n*p)` -> `C(m*p)`
- `array_transpose` — транспонирование матрицы (поменять строки и столбцы местами)
- `array_det` — определитель квадратной матрицы (для типа numeric)
- `array_inv` — обратная матрица (через алгебраические дополнения и транспонирование; если существует)
- `array_solve` — решение системы линейных уравнений `Ax = b`

**Ограничения:**
- Массивы, переданные в функции, должны иметь один и тот же тип данных

## 2. Используемые решения и алгоритмы

### Алгоритмы и обоснование

1. **`array_dot` (Скалярное произведение):**
   - *Алгоритм:* Итеративное суммирование произведений соответствующих элементов векторов: $\sum (a_i \cdot b_i)$.
   - *Сложность:* `O(n)`.
   - *Обоснование:* Линейная сложность по времени, `O(1)` по памяти.

2. **`array_matmul` (Умножение матриц):**
   - *Алгоритм:* Классический алгоритм c 3-мя вложенными циклами: $result[i][j] = \sum_{k} A[i][k] \cdot B[k][j]$.
   - *Сложность:* `O(m*n*p)` по времени, `O(m*p)` по памяти.
   - *Обоснование:* Размеры матриц небольшие; быстрые алгоритмы (Strassen) эффективны только при n > 100 и требуют больше дополнительной памяти для хранения промежуточных результатов.

3. **`array_transpose` (Транспонирование):**
   - *Алгоритм:* Перестановка элементов через перебор индексов `result[j][i] = A[i][j]`.
   - *Сложность:* `O(m*n)` по времени, `O(m*n)` по памяти.
   - *Обоснование:* Прямая реализация; минимально возможная сложность; не требует дополнительной памяти кроме выходной матрицы.

4. **`array_det` (Определитель):**
   - *Алгоритм:* Рекурсивное разложение по первой строке через поиск миноров. Базовый случай для матриц $1 \times 1$ и $2 \times 2$.
   - *Сложность:* `O(n!)` по времени.
   - *Обоснование:* Оптимально для матриц малого и среднего размеров (n ≤ 10-15). Типичные матрицы небольшие, поэтому факториальная сложность не критична.

5. **`array_inv` (Обратная матрица):**
   - *Алгоритм:* Вычисление через матрицу алгебраических дополнений, ее транспонирование и деление на определитель: $A^{-1} = \frac{1}{\det(A)} C^T$.
   - *Сложность:* `O(n!)` по времени.
   - *Обоснование:* Классическая точная формула без итераций; переиспользует уже реализованные функции; хорошо работает для матриц небольшого размера.

6. **`array_solve` (Решение СЛАУ $A \cdot x = b$):**
   - *Алгоритм:* Нахождение решения системы линейных уравнений через нахождение обратной матрицы $A^{-1}$ и умножение на вектор $b$: $x = A^{-1} \cdot b$.
   - *Сложность:* `O(n!)` по времени.
   - *Обоснование:* Переиспользует уже реализованную функцию array_inv; математически корректный подход для невырожденных матриц; простота реализации.

## 3. Предполагаемые тесты (`pg_regress`)

### Общие сценарии
- Передача `NULL` аргументов.
- Передача пустых массивов или массивов некорректной размерности (3D и выше).

### Специфические сценарии по функциям
- **`array_dot`:** Корректные векторы одинаковой длины (положительные, отрицательные, дробные числа); ошибка при разной длине векторов.
- **`array_matmul`:** Умножение матриц `2*2`, прямоугольные матрицы; ошибка при несоответствии внутренних размерностей ($n \neq k$).
- **`array_transpose`:** Транспонирование прямоугольной матрицы `2*3` -> `3*2`.
- **`array_det`:** Расчет для матриц `1*1`, `2*2`, матрицы с нулевым определителем.
- **`array_inv`:** Обращение единичной или диагональной матрицы, проверка свойства $A \times A^{-1} \approx I$; ошибка для матрицы с нулевым определителем.
- **`array_solve`:** Решение системы (например, $A = [2, 1],[1, 1], b = [5, 3] -> [2, 1]$).
