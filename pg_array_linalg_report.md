# Промежуточный отчёт по расширению pg_array_linalg

## 1. Описание реализованных функций

### array_dot(anyarray, anyarray) → numeric
**Описание**: Вычисляет скалярное произведение двух векторов (одномерных массивов одинаковой длины).  
**Входные параметры**: Два одномерных массива числового типа.  
**Возвращает**: `numeric` - скалярное произведение.  
**Ограничения**: Оба аргумента должны быть 1D массивами одинаковой длины. `NULL` возвращает `NULL`.

### array_matmul(anyarray, anyarray) → anyarray
**Описание**: Умножает две матрицы. Первая матрица размерности $m \times n$, вторая — $n \times p$. Результат — $m \times p$.  
**Входные параметры**: Двумерные массивы (матрицы) числового типа.  
**Возвращает**: Матрица того же типа, что и входные.  
**Ограничения**: Количество столбцов первой матрицы должно равняться количеству строк второй. `NULL` возвращает `NULL`.

### array_transpose(anyarray) → anyarray
**Описание**: Транспонирует матрицу (меняет местами строки и столбцы).  
**Входные параметры**: Одномерный или двумерный массив числового типа.  
**Возвращает**: Транспонированная матрица того же типа.  
**Ограничения**: Для 1D массива возвращает вектор исходного типа.

### array_det(anyarray) → numeric
**Описание**: Вычисляет определитель квадратной матрицы.  
**Входные параметры**: Двумерный массив (квадратная матрица) числового типа.  
**Возвращает**: `numeric` - определитель матрицы.  
**Ограничения**: Матрица должна быть квадратной. `NULL` возвращает `NULL`.

### array_inv(anyarray) → anyarray
**Описание**: Вычисляет обратную матрицу (если существует).  
**Входные параметры**: Двумерный массив (квадратная матрица) числового типа.  
**Возвращает**: Обратная матрица того же типа (при приведении результатов вычислений с плавающей точкой к типу элементов исходной матрицы).  
**Ограничения**: Матрица должна быть квадратной и невырожденной ($|det| \ge 10^{-12}$).

### array_solve(anyarray, anyarray) → anyarray
**Описание**: Решает систему линейных уравнений $A \cdot x = b$, где $A$ — квадратная матрица, $b$ — вектор.  
**Входные параметры**: $A$ — квадратная матрица, $b$ — вектор (одномерный массив).  
**Возвращает**: Вектор $x$ — решение системы.  
**Ограничения**: Матрица $A$ должна быть квадратной и невырожденной. Размерности должны быть совместимы.

## 2. Тестовые наборы данных и расширенный крайний контроль

### Набор 1: Базовые функциональные тесты
- **Цель**: Проверить корректность работы функций на стандартных вещественных и целых данных.
- **Примеры**: 
  - `array_dot`: `ARRAY[1,2,3]` $\times$ `ARRAY[4,5,6]`
  - `array_matmul`: `[[1,2],[3,4]]` $\times$ `[[5,6],[7,8]]`
  - `array_det`: `[[1,2],[3,4]]`

### Набор 2: Проверка NULL значений и некорректных размерностей
- **Цель**: Проверить обработку `NULL` и несовместимых аргументов.
- **Ожидаемый результат**: `NULL` при `NULL`-входах; генерация ошибок уровня `ERROR` при разной длине векторов или неквадратных матрицах.

### Набор 3: Специальные случаи и точность типов
- **Цель**: Оценка поведения на границах диапазонов базовых типов C/Postgres (`int4`, `int8`, `numeric`).
- **Примеры краевых проверок**:
  - Извлечение элементов из обратной матрицы: `(array_inv(ARRAY[[2,0],[0,2]]))[1][1]`
  - Умножение предельных целочисленных значений (допустимое знаковое переполнение `int4`/`int8`).
  - Операции над типом `numeric` в диапазоне выше $2^{53}$ (`9007199254740993::numeric`).

## 4. Архитектура вычислений и системные ограничения

### 1. Единое внутреннее представление
Все математические преобразования (определитель, вычисление алгебраических дополнений, умножение, решение СЛАУ) производятся над внутренней структурой `pg_matrix`, содержащей строки типа `double**` (`double precision`).


### 2. Ограничения расширения
1. **Поддерживаемые типы данных**: `int2`, `int4`, `int8`, `float4`, `float8`, `numeric`.
2. **Внутреннее представление**: все матричные вычисления выполняются с использованием чисел с плавающей точкой двойной точности (`double precision` / `float8`).
3. **Ограничения точности для типа numeric**:
  - Точность вычислений ограничена 53-битной мантиссой типа `double precision`.
  - Большие значения, такие как `9007199254740993::numeric` ($2^{53} + 1$), при конвертации во внутреннее представление теряют точность. Так, в тестах определителя и транспонирования матриц для этого числа фиксируется значение `9007199254740990`.
4. **Ограничения для целочисленных типов**:
  - Для больших целых чисел действуют те же аппаратные ограничения точности `double`.
  - Возвращаемые целочисленные элементы матриц округляются до ближайшего целого с помощью функции `round()`. При операциях с граничными значениями (например, для максимального `int4` значения `2147483647` или `bigint` `9223372036854775807`) может происходить переход к минимальному отрицательному числу (например, `-2147483648` или `-9223372036854775808`).
5. **Проверка вырожденности матрицы**:
  - Матрица считается вырожденной, если абсолютное значение её определителя меньше заданного порога: $\vert{}det\vert{} < 10^{-12}$.
  - Матрицы с крайне малыми определителями могут ошибочно классифицироваться как вырожденные из-за погрешностей округления `double`.
